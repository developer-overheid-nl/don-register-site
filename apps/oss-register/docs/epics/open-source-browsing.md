# EPIC: open source browsing

**Probleem/doel:** Developers moeten kunnen inschatten of

- een project veilig genoeg is om her te gebruiken,
- of het mogelijk is om op termijn bij te dragen aan het project.

**Scope:** De analyse die we doen geldt voor open source overheidsprojecten in het register.

**Succescriterium:** Deze epic is af als een developer in korte tijd een project kan beoordelen op open source kwaliteit en het gevoel heeft die hij een gefundeerde keuze kan maken over hergebruik.

## User stories

**Als** developer,
**wil ik** de opensource-status van een project in kunnen zien,
**zodat** ik kan beoordelen of het slim is om een project her te gebruiken.
